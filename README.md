# Python Practice Projects 🚀

A collection of beginner-friendly Python scripts covering basic logic, math, and data structures.

## 📂 Project Overview


| Project Name | Description |
| :--- | :--- |
| **2D Collections** | Exploring nested lists and multi-dimensional data. |
| **Compound Interest Calculator** | Calculates investment growth over time. |
| **Countdown Timer** | A simple console-based timer with a countdown. |
| **Formatting Specifiers** | Practice with string formatting and f-strings. |
| **Python Quiz** | A multiple-choice quiz game. |
| **Q Triangle** | Logic for calculating or printing triangle patterns. |
| **Shopping Cart** | Adds items to a list and calculates the total price. |
| **Temperature Converter** | Switches between Celsius and Fahrenheit. |
| **Weight Converter** | Converts weight between Kilograms and Pounds. |

## 🛠️ How to Use
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the folder:
   ```bash
   cd your-folder-name
   ```
3. Run any script using Python:
   ```bash
   python script_name.py
   ```

## 📝 Learning Goals
* Mastering basic Python syntax.
* Understanding user input and data type conversion.
* Working with loops, conditionals, and collections.
